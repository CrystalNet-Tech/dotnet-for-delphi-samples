# .Net Runtime Library for Delphi Samples

[.Net Runtime Library for Delphi](https://crystalnet-tech.com/RuntimeLibrary/RuntimeLibrary4Delphi) is the best library to work with .Net framework and .Net libraries from Delphi. It is designed to provide a way to interact with applications written in anyone of the .Net languages (such as C#, Visual Basic.Net, Delphi.Net, JScript.Net, etc) from Delphi.

# What the .Net Runtime Library for Delphi can do:
<ul>
    <li>Access .Net Framework Class Library (such as Collections, IO, Networking, Security, Cryptogrphy etc).</li>
    <li>Access 3rd Party .Net Libraries.</li>
    <li>Hosts the .Net Common Language Runtime (CLR) in Delphi.</li>
    <li>Can load and access assemblies/types from 3rd party .Net libraries or executable files.</li>
    <li>Can load and access .Net assemblies/types from Global Assembly Cache (GAC)</li>
    <li>Can invoke members of a .Net types (such as constructor, fields, properties, methods and events).</li>
    <li>Can create instance of .Net object.</li>
    <li>Can handle .Net exceptions.</li>
    <li>Can handle, access and invoke .Net events.</li>
    <li>Can host .Net controls in Delphi VCL Forms.</li>
    <li>...and many more.</li>
</ul>

# Competitive Advantages
<ul class="bullets_red">
    <li>Full access to .Net Framework Class Library (Including new and emerging .NET technologies).</li>
    <li>No extra dll is required when deployed.</li>
    <li>No COM registration of .Net Libraries is required when deployed.</li>
    <li>There are tools to generate your .Net Libraries into Delphi pas files.</li>
    <li>Allows Delphi to consume .Net libraries as if they were native code.</li>
    <li>Easy to use.</li>
</ul>
