#### .Net GZipStream - Compress/Decompress a String in Delphi

This sample demonstates how to use .Net GZipStream to compress and decompress string in Delphi.

The sample presents two methods to compress and decompress strings using _CNClrLib.IO._GZipStream_ using the [.Net Runtime Library for Delphi](https://crystalnet-tech.com/RuntimeLibrary/RuntimeLibrary4Delphi.aspx)
