### How to get attributes of a file and directory in Delphi

This sample shows how to get attributes of a file and directory in Delphi using the GetAttr function in the [.Net Runtime Library for Delphi](https://crystalnet-tech.com/RuntimeLibrary/RuntimeLibrary4Delphi.aspx).

This sample uses the **GetAttr** function to determine the attributes of a file and directory or folder.
