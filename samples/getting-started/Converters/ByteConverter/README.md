### Convert between types using TypeDescriptor in Delphi

This sample shows how to convert between types with TypeDescriptor interface in Delphi using the [.Net Runtime Library for Delphi](https://crystalnet-tech.com/RuntimeLibrary/RuntimeLibrary4Delphi.aspx)

The sample demonstrates how to declare and initialize an 8-bit unsigned integer and a string and then converts each of them to the other's type, respectively.
