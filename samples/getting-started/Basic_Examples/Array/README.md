### How to use .Net Array in Delphi

Using the [.Net Runtime Library for Delphi](https://crystalnet-tech.com/RuntimeLibrary/RuntimeLibrary4Delphi.aspx), you can create and initialize .Net array of any type in Delphi and display the content of the array.

The sample demonstrates how to create and initialize an array of any type, an array of object and an array of double and how to display its values using the Runtime Library for Delphi.
