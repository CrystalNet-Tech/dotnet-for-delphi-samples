### Handle and raise .Net events in Delphi (Standard)

This sample shows how to raise .Net events and handle these events from Delphi using the [.Net Runtime Library for Delphi](https://crystalnet-tech.com/RuntimeLibrary/RuntimeLibrary4Delphi.aspx). The sample demosntrates how to register the .Net event called StateChange and raised in a _stdcall_ event handler method named _StateChangeEventHandler_.
