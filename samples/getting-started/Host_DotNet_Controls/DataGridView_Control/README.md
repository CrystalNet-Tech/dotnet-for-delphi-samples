How to host .Net DataGridView Controls in Delphi
This demo shows how to host DataGridView control, load data from a dataset and display the data in the datagridview.

This demo shows how to host the .Net control called DataGridView and also demonstrates how to load data from a DataSet and display the data in the DataGridView control. 

A .Net control can be hosted in a Delphi VCL form application using the TClrContainer which is a special container for hosting .Net controls as well as WPF custom controls in Delphi. This container is part of the .Net Runtime Library for Delphi.
