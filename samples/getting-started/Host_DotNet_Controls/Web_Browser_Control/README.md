### .Net Web Browser Control in Delphi

This sample demonstrates how to create your own web browser(starter) with the .Net Web Browser Control in Delphi using the [.Net Runtime Library for Delphi](https://crystalnet-tech.com/RuntimeLibrary/RuntimeLibrary4Delphi.aspx).

C# Web Browser actually provides an Internet Explorer control, which has different properties, methods, and events.
