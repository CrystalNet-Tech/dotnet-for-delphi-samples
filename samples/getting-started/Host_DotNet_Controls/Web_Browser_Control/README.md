.Net Web Browser Control in Delphi
How to create your own web browser(starter) with the .Net Web Browser Control in Delphi using the .Net Runtime Library for Delphi

C# Web Browser actually provides an Internet Explorer control, which has different properties, methods, and events. 


This demo demonstrates how to create your own web browser with the .Net Web Browser Control in Delphi using the .Net Runtime Library for Delphi.
