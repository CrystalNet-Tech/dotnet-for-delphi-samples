### How to use different .Net Collection types in Delphi

This sample shows how to use .Net Collection types such as StringCollection, Stack, Queue, Hashtable, SortedList etc in Delphi.

The sample demonstrates how to create and initialize .Net array of string, ArrayList, StringCollection, StringDictionary, Stack, Queue, BitArray, HashTable and SortedList and how to display its values using the [Runtime Library for Delphi](https://crystalnet-tech.com/RuntimeLibrary/RuntimeLibrary4Delphi.aspx).
